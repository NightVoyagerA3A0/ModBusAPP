# ProgramVibeCodeQuestions

## 问题 1
为什么 `ProgramVibeCode` 只负责创建 `Application` 和主窗口，而不直接在入口里写模拟器、调度器甚至串口初始化？

### 思考方向
- 入口层、表现层、业务层分别应该承担什么职责。
- 如果入口方法写太多初始化细节，后续做单元测试和替换界面会遇到什么问题。
- “简单入口，复杂逻辑下沉”为什么是一种常见工程实践。

## 问题 2
WPF 入口方法上为什么常见 `[STAThread]`？

### 思考方向
- COM 单线程单元模型和 WPF UI 线程之间有什么关系。
- 为什么很多 UI 组件要求在特定线程模型下工作。
- 如果丢掉这个特性，可能出现哪些运行时问题。
